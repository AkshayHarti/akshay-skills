# Hooks and the fold

LinkedIn shows roughly **140–200 characters** before "…see more" on mobile —
two short lines. Everything after that is opt-in. The hook's only job is to earn
the second line.

## Rules

- The number or the tension appears in **line 1**. Not line 3.
- Line 1 is under ~90 characters. Line 2 is a separate idea, not a continuation
  of a long sentence.
- No preamble. Delete every opening that exists to warm up.
- The hook must be true without the rest of the post. If it needs the body to
  make sense, it is a title, not a hook.

## Patterns that work

| Pattern | Example | Why it works |
|---|---|---|
| Number first | `38 minutes to 4. 1,400 deploys.` | Concrete, falsifiable, no adjectives needed |
| Replacement | `We deleted the staging environment. Deploy confidence went up.` | Contradiction in two lines |
| Cost of the status quo | `Our eval suite costs $9k/month and caught 2 regressions.` | Implies the argument without making it |
| Deliberate tradeoff | `We chose the slower option on purpose.` | Sets up "here's the math" |
| Reframe | `This isn't an AI problem. It's a p95 problem.` | Reclassifies the reader's mental model |
| Specific failure | `One missing index took checkout down for 11 minutes.` | Stakes + precision |
| Rule | `No dashboard ships without the decision it drives.` | Opinionated, quotable, invites disagreement |
| Before/after table | `Before / After` + two columns | Skimmers get the whole post from the fold |

## Openings that get the post closed

- `Excited to share…` / `Thrilled to announce…` / `Humbled to…`
- `I've been thinking a lot about…`
- Any rhetorical question: `Ever wondered why…?`
- `Unpopular opinion:` — if it needs the label, it is not unpopular
- `Let that sink in.` / `Read that again.`
- `In today's fast-paced AI landscape…`
- Emoji as line 1 with no content
- A definition of a common word

## Hook variants

Always produce **three** hooks from different patterns, then pick one. Three
variants of the same pattern is one hook written three times. Test each by
asking: *would I stop scrolling if a stranger wrote this?*
